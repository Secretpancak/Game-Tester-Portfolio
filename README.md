## Bug Report examples that i've done myself:

### Title:PC][FUN][NPC] The npc attacks the women npc instead of the player

### Steps to reproduce:

1.Open the game

2.Start a new game

3.Get to the 4th main mission

4.Get to the end section of the mission

5.Get infront of the main target and wait for him to alert the guards

6.Observe the guard on the right fighting the NPC not the main character

### Observed results:

After the main target alerts the guards the guard on the right side fights the NPC on the couch instead of the main character.

### Expected results:

The guard gets agro and attacks the main character instead of the NPC on the couch.

## 2nd Bug Report example:

### Title: PC][UI][Overlay] UI overlay with all ability buttons in-game and unit summuries

### Steps to reproduce:

1.Open the game

2.Go inside of any available gamemode

3.After loading in into the game start the game 

4.Place down 2 units or more that have any avaible abilities whenever you gonna have enough currency

5.Upgrade the unit until it will show a useable ability

6.Click on that unit and keep the UI opened

7.Position the ability button on top of a random unit you’ve placed before

8.Hover your mouse over the ability button when its still positioned over a random unit on the map

9.Observe the unit UI overlay the ability button

### Actual results:

The unit’s UI positioned behind the ability button overlays the ability button whenever the player hovers over it and he needs to hover his mouse from a diffrent way to actually see the ability’s description.

### Expected results:
The unit's ability Menu UI shows up whenever the player hovers his mouse over the ability button giving him the description of what the ability does.
